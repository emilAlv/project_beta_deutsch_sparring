# wort. – CEFR A1–B1 communicative curriculum map

## Purpose and authority

This is an **original, locally designed syllabus**, not an officially issued curriculum or accredited exam. The Common European Framework of Reference for Languages (CEFR) provides calibrated can-do outcomes rather than a mandatory list of grammar chapters. Goethe-Institut exams inform expected communicative performance. The Swiss State Secretariat for Migration's fide framework uses scenario-based language learning grounded in everyday life in Switzerland.

## Instructional design

**Progression within each lesson:** meaningful input (a short situation, dialogue or notice) → information extraction → limited support and focus on form → goal-oriented interaction → an unexpected response requiring repair/negotiation → production or mediation → spaced reactivation in another context.

**Four CEFR modes:**
- **Reception:** read short written notices/dialogues; listening requires a real audio or text-to-speech presentation to be assessed.
- **Production:** compose a relevant reply, personal description, explanation or short message; spoken production requires microphone/audio support to be assessed.
- **Interaction:** negotiate meaning, ask follow-up questions, change plans and repair misunderstandings across multiple turns.
- **Mediation:** relay a notice to someone else, simplify a short text, or paraphrase another person's position (not merely literal translation).

At present, all four modes can be *represented in writing*; the application **does not yet verify listening comprehension, pronunciation, spoken fluency or live face-to-face interaction**. Do not claim complete CEFR certification coverage from these materials alone.

## Retrieval and variation rules

1. Review the current session goal in a different situation, not by merely swapping names.
2. Alternate reading/understanding, guided language production, dialogue, brief writing and mediation whenever the exercise format supports them.
3. Use target structures as resources for meaning; do not penalise an understandable, level-appropriate answer just because it differs from the authored model.
4. Prioritise serious comprehension-changing errors, then the lesson's target structure; give concise feedback, ask the learner to retry if helpful, and continue the interaction.
5. Revisit earlier topics and typical errors in later units, using the existing word-score repetition rules where applicable; a grammar lesson is not by itself proof of mastery.
6. Use Swiss Standard German spelling (ss, not ß) by default. Accept legitimate German-standard alternatives. Never imply that Swiss German dialect and Swiss Standard German are the same thing.
7. Keep texts concise at A1, build two-to-four-sentence communication at A2, and expect increasingly connected explanations, justified decisions and summaries at B1.
8. Avoid stereotypical assumptions about nationality, family, professions or local customs. Allow learners to use imaginary personal details.

## Authenticity and intellectual-property boundaries

All texts in the lesson files are **original simulations** of everyday materials; do not describe a fictional timetable, notice, rental advert or message as an actual public announcement. Real legal, health, tenancy and administrative questions require current official sources; never fabricate binding policy advice. The content is inspired by CEFR/fide skill domains, not copied from `Schritte plus Neu`, Goethe exam tasks or fide model exams.

## Assessment observations

Use formative feedback rather than certifying CEFR levels. Suggested qualitative evidence:

| Criterion | A1 | A2 | B1 |
|---|---|---|---|
| Task success | Conveys essential personal information with help | Completes a routine exchange and clarifies a simple obstacle | Resolves a familiar problem or sustains an explanation |
| Comprehensibility | Basic phrases understood with repetition | Connected short utterances understood with occasional repair | Main line of reasoning understandable and coherent |
| Interaction | Answers and asks short predictable questions | Responds to a follow-up and offers a basic alternative | Builds on others' contributions and negotiates |
| Accuracy | Frequent errors acceptable when meaning clear | Errors acceptable when task still succeeds | Control sufficient for meaning; limited errors tolerated |
| Mediation | Relays a single predictable detail | Summarises a short familiar notice | Explains main points of a familiar text to someone else |

These are **local formative rubrics**, not verbatim official assessment grids.

## Coverage audit – still to improve

- **Real listening:** scripted dialogues need audio playback and controlled listening tasks (Codex integration / later development).
- **Spoken production and pronunciation:** no microphone input or validated phonological assessment in this content-only change.
- **Longer reading:** especially B1, add genuinely coherent multi-paragraph original texts with comprehension tasks; avoid confusing text length with level.
- **Extended written interaction:** B1 email chains and replies need fuller multi-turn assignments and valid alternative-response evaluation.
- **Intercultural mediation:** expand neutral cases that involve different perspectives, while avoiding oversimplification or stereotypes.
- **Vocabulary breadth:** current `vocab/words.json` is a separate repository-managed word bank; this work has **not** independently audited it for CEFR coverage.
- **Validated grammar checking:** some existing `MOCK=1` grammar examples rely on fixed solutions; communicate acceptable alternatives to the evaluator rather than treating examples as the only correct answer.
- **UI labels:** all new communication-oriented lesson files currently use `Typ: Grammatik` so the existing loader offers them on the grammar track. This is a technical compatibility label, **not** an assertion that the lessons are grammar-only. Codex should present a suitable learner-facing label without breaking existing identifiers.
- **Source checks:** at least one independent teacher or proficient reviewer should spot-check idiomatic German, variant choice and assessment fairness before public release.
- **Level claims:** unit availability is A1/A2/B1, but successful completion of a finite question set is **not evidence of overall level attainment**.

## Repository ownership and future extension

Curriculum content is owned on `curriculum/a1-b1-natural-learning` (the `content/` directory plus this curriculum map). Codex integration belongs on `integration/cefr-natural-sparring`. Keep changes in separate branches until review.
